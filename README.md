# OctaveClient

Десктопный музыкальный плеер для Windows: SoundCloud-стриминг, аккаунты, коллекция,
очередь, радио и Discord-активность с обложкой трека.

## Установка

1. Скачайте **OctaveLoader.exe** и **loader.ini** из [последнего релиза](../../releases/latest).
2. Положите оба файла в одну папку (например `D:\OctaveClient`).
3. Запустите `OctaveLoader.exe`.

Лоадер скачает плеер (~150 МБ), распакует рядом с собой и запустит.
Дальше плеер стартует за 2 секунды — распаковки больше нет.

Windows покажет предупреждение SmartScreen (файл без цифровой подписи):
**«Подробнее» → «Выполнить в любом случае»**.

## Discord

Плеер сам подключается к запущенному Discord. Один раз нужен Application ID:
создайте приложение на [discord.com/developers](https://discord.com/developers/applications),
нажмите «Copy ID» на странице General Information — плеер подхватит его из буфера обмена.

## Данные

Аккаунты, избранное и плейлисты хранятся локально в `app\OctaveClientData`.
При обновлении версии лоадер их не трогает.

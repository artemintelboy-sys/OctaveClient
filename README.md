# OctaveClient

Десктопный музыкальный плеер для Windows: SoundCloud-стриминг, аккаунты, коллекция,
очередь, радио и Discord-активность с обложкой трека.

![version](https://img.shields.io/badge/version-1.0.0-8b7bff)

## Установка (30 секунд)

1. Откройте [последний релиз](../../releases/latest).
2. Скачайте **OctaveLoader.exe** и **loader.ini** (вместе ~95 КБ).
3. Положите оба файла в одну папку, например `D:\OctaveClient`.
4. Запустите `OctaveLoader.exe`.

Лоадер скачает плеер (~150 МБ), распакует рядом с собой в папку `app` и запустит.
Первый запуск — около 30 секунд, дальше **2 секунды**: распаковки больше нет.

> Windows покажет предупреждение SmartScreen, потому что файл без цифровой подписи:
> **«Подробнее» → «Выполнить в любом случае»**.

## Discord

Плеер подключается к запущенному Discord сам и показывает трек, исполнителя,
обложку, паузу и живой таймер.

Один раз нужен Application ID:

1. [discord.com/developers/applications](https://discord.com/developers/applications) → **New Application**.
2. **General Information** → **Copy ID**.
3. Плеер подхватит ID из буфера обмена автоматически.

## Данные

Аккаунты, избранное и плейлисты — локально, в `app\OctaveClientData`.
При обновлении версии лоадер их сохраняет.

## Обновление версии

Замените `OctaveClient.zip` в новом релизе — лоадер скачает его сам
при следующем запуске с флагом `--update`, либо после удаления папки `app`.
